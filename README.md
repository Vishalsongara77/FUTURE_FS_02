# 🌟 FUTURE FS 02 — Weather App

Live Demo: https://vishalsongara77.github.io/FUTURE_FS_02/

## 🚀 About
**FUTURE FS 02** is a responsive weather forecast web application built with **React**. It fetches real-time weather data and displays conditions, temperature, and forecast for searched cities with a dynamic and engaging interface.

This project showcases:
- React component structure
- API integration with a weather service
- Dynamic UI updates and responsive design
- Practical use of modern CSS

## 🛠 Features
- Search cities for weather info
- Real-time weather data display
- Clean and responsive UI
- Smooth user interaction

## 🧠 Motivation
I created this project to improve my frontend skills, specifically:
- Working with API data
- Building reusable components
- Making a UI that looks good and works well on desktop and mobile

It was also a fun way to learn how to handle asynchronous data and conditional rendering in React.

## 📍 Built With

This project was built using:

- **React** – Frontend library for UI  
- **CSS** – Styling and responsive layout  
- **Weather API** – For real-time weather data
